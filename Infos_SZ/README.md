# Infos_SZ: what this version of ALF adds

This repository (`github.com/samizwei/ALF`) is the standard ALF code
(https://alf.physik.uni-wuerzburg.de) with two extra Hamiltonians for the two-band model of
Christensen *et al.*, PRL **125**, 247001 (2020), together with run and analysis scripts.

**How to install, run and analyse:** see `ALF_SZ_Manual.pdf` in this folder (source: `ALF_SZ_Manual.tex`).

## The models

Fermions c, d on an L1×L2 square lattice, spin α ∈ {↑,↓}, with
S^a_i = Σ_αβ c†_iα σ^a_αβ d_iβ + h.c.

    H = H_0 − U Σ_i Σ_{a ∈ A} (S^a_i)²
        A = {z}         Ising (the paper, Eq. 3)
        A = {x, y}      XY
        A = {x, y, z}   Heisenberg

H_0 is Eq. (1) of the paper in real space (paper values t = 1, δ = 0.4, μ = −2). All three
models are sign-free for U > 0.

## Files added or changed with respect to standard ALF

### Hamiltonians (Fortran)

| file | status | content |
|---|---|---|
| `Prog/Hamiltonians/Hamiltonian_Hubbard_Sz_smod.F90` | new | **Ising** model only. Gauge d_↓ → −d_↓, then N_FL = 1, N_SUN = 2, 2 orbitals per site (c, d). Parameters in `&VAR_Hubbard_Sz`. Validated against ED on 2×2. |
| `Prog/Hamiltonians/Hamiltonian_TwoBand_Spin_smod.F90` | new | **Ising, XY and Heisenberg**, selected with `Ham_Int` in `&VAR_TwoBand_Spin`. Original basis, N_FL = N_SUN = 1, 4 orbitals per site (c↑, c↓, d↑, d↓), one HS field per site and spin component. Validated against ED on 2×2. |
| `Prog/Hamiltonians.list` | changed | two lines added, `Hubbard_Sz` and `TwoBand_Spin`, so that `make` compiles the new models. |

The files `Prog/Hamiltonians/Hamiltonian_*_read_write_parameters.F90`,
`Prog/Hamiltonians_case.h` and `Prog/Hamiltonians_interface.h` are **generated by `make`**
(by `Prog/parse_ham.py`) and are therefore not in git. No other ALF source file was modified.

For the Ising coupling the two Hamiltonian files produce identical Monte Carlo trajectories
(to round-off). `Hubbard_Sz` works with half the matrix dimension and is about a factor 4
faster (measured: 4×4 lattice, β = 2, 4 s vs. 16 s),
so use it for Ising production runs and `TwoBand_Spin` for XY and Heisenberg.

### Observables (both Hamiltonians)

| name | type | meaning |
|---|---|---|
| `Kin`, `Pot`, `Ener`, `Part` | scalar | ⟨H_0⟩ (incl. band offsets), ⟨H_int⟩, sum, ⟨N⟩ |
| `Part_cd` | scalar | (⟨N_c⟩, ⟨N_d⟩) |
| `Green`, `Den` | eq. / tau | orbital-resolved Green function and density correlations |
| `SpinZ` (and `SpinX`, `SpinY` in TwoBand_Spin) | eq. / tau | ⟨S^a_i S^a_j⟩ |
| `Pair` | eq. / tau | ⟨P†_i P_j⟩, P_i = 2(c_i↑c_i↓ − d_i↑d_i↓) (s± pairing of the paper) |

### Scripts and parameter files

| file | content |
|---|---|
| `Scripts_and_Parameters_files/Hubbard_Sz/run.sh` | sets up a run directory (anywhere), runs `ALF.out`, runs `ana.out`, prints a summary; continues a run if called again. Model independent. |
| `Scripts_and_Parameters_files/Hubbard_Sz/out_to_in.sh` | used by `run.sh` to continue from the last configuration |
| `Scripts_and_Parameters_files/Hubbard_Sz/analyze.py` | Python analysis: summary table, thermalisation and S(q) plots, Δτ² extrapolation |
| `Scripts_and_Parameters_files/Hubbard_Sz/parameters` | template for the Ising model (`Hubbard_Sz`) |
| `Scripts_and_Parameters_files/Hubbard_Sz/parameters_test_2x2` | 2×2 test with known ED results |
| `Scripts_and_Parameters_files/Hubbard_Sz/seeds` | random seeds (copied into each run) |
| `Scripts_and_Parameters_files/Hubbard_Sz/README.md` | short instructions for the Ising model |
| `Scripts_and_Parameters_files/TwoBand_Spin/run.sh` | wrapper that calls `../Hubbard_Sz/run.sh` with the TwoBand_Spin template as default |
| `Scripts_and_Parameters_files/TwoBand_Spin/parameters` | template for `TwoBand_Spin` (set `Ham_Int`) |
| `Scripts_and_Parameters_files/TwoBand_Spin/parameters_test_2x2` | 2×2 Heisenberg test with known ED results |
| `Scripts_and_Parameters_files/TwoBand_Spin/seeds` | random seeds |

## Quick start

    git clone https://github.com/samizwei/ALF.git ALF_SZ
    cd ALF_SZ
    source configure.sh GNU noMPI
    make
    cd Scripts_and_Parameters_files/Hubbard_Sz
    ./run.sh ~/QMC_runs/Sz_test_2x2 parameters_test_2x2      # ~5 s, compare with ED
    python3 analyze.py ~/QMC_runs/Sz_test_2x2 --plot

Expected: `Ener = -31.8098(72)` (ED: −31.80783), average sign 1.

Keep simulation data **outside** this repository (here `~/QMC_runs/`); see the manual, Sec. 3.
